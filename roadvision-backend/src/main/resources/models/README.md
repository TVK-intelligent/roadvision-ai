# THƯ MỤC LƯU TRỮ MÔ HÌNH AI YOLO (.ONNX)

- Tệp mô hình chuẩn: `yolov8_roadcare.onnx`
- Khi có mô hình đã train, bạn chỉ cần copy tệp `yolov8_roadcare.onnx` vào thư mục này.
- Kích thước đầu vào chuẩn: `1 x 3 x 640 x 640`
- Các lớp nhận diện mục tiêu:
  0: POTHOLE (Ổ gà / Hố sụt)
  1: ROAD_CRACK (Vết nứt mặt đường)
  2: ROAD_OBSTACLE (Chướng ngại vật / Rác)
  3: ROAD_FLOODING (Điểm ngập úng)
