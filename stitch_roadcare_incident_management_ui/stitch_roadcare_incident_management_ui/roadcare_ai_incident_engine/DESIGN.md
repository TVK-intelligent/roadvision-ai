## Brand & Style

This design system drives an mission-critical AI-powered municipal infrastructure and road safety intelligence platform. The visual aesthetic fuses high-efficiency enterprise utility with the precision and clarity of mission-control telemetry. It is engineered for civil engineers, emergency dispatchers, and smart-city operators who require rapid decision velocity under complex, data-dense conditions.

The design movement is **Corporate Modern with High-Precision Technical Accents**:
- **Clarity over ornament:** Pure, crisp white and subtle slate-tinted canvas backdrops anchor high-density data visualizations without cognitive fatigue.
- **Instrument-grade feedback:** Visual elements communicate real-time incident detection, confidence scores, and geospatial alerts through calibrated color-coding, bounding markers, and high-visibility status telemetry.
- **Controlled density:** Information architecture balances tight, scannable data grids with generous, breathing dashboard containers to keep cognitive load low during crisis triage.

## Colors

The palette establishes an authoritative, reliable environment using operational blues, balanced by functional categorical and status tokens designed for mission-critical legibility.

### Core Swatches
- **Primary Operational:** Deep Blue `#1E40AF`, Electric Blue `#2563EB` (Primary Main), Vivid Active Blue `#3B82F6`.
- **Secondary Telemetry:** Sky Blue `#0284C7` for spatial tracking, sub-metrics, and aerial mapping indicators.
- **Muted Structural Slate:** Slate `#475569` and Neutral Slate `#64748B` for tertiary structures, secondary typography, and neutral controls.
- **Surfaces & Borders:** Base Canvas `#F8FAFC`, Pure Surface `#FFFFFF`, Surface Border `#E2E8F0`, Surface Border Subtle `#F1F5F9`.

### Incident Domain Classifications
- **Pothole Alert:** Amber `#F59E0B` (Surface tint: `#FEF3C7`, Stroke: `#FDE68A`)
- **Road Crack Analysis:** Purple / Indigo `#6366F1` (Surface tint: `#EEF2FF`, Stroke: `#E0E7FF`)
- **Road Obstacle Hazard:** Rose / Red `#EF4444` (Surface tint: `#FEE2E2`, Stroke: `#FECACA`)
- **Road Flooding Crisis:** Cyan / Teal `#06B6D4` (Surface tint: `#CFFAFE`, Stroke: `#A5F3FC`)

### Operational Status Flow
- **Resolved / Optimal:** Emerald `#10B981` (Surface tint: `#D1FAE5`)
- **In Progress / Dispatched:** Blue `#3B82F6` (Surface tint: `#DBEAFE`)
- **Pending Review / Triage:** Yellow `#EAB308` (Surface tint: `#FEF9C3`)

Always pair tinted backgrounds with their dominant saturated accent for text and boundary lines to maintain WCAG AAA contrast compliance across all monitoring views.

## Typography

The typography strategy leverages a clear distinction of responsibilities:
1. **Headings (Plus Jakarta Sans):** Modern, geometric, and structured. Conveys progressive authority and clean contemporary styling across system dashboards and reports.
2. **Interface & Body (Inter):** Highly legible, neutral workhorse engineered for complex data entry, filter panels, and high-frequency dispatch feeds.
3. **Telemetry & Sensor Data (JetBrains Mono):** Monospaced precision for tabular numeric alignments, confidence percentages, GPS coordinates, vehicle registration IDs, and timecode overlays.

## Layout & Spacing

This design system uses an adaptable, fixed-flexible hybrid grid system tailored to spatial incident management:
- **Desktop (>= 1280px):** 12-column grid system with dynamic canvas flex. Left navigation is pinned at `17.5rem` (`280px`), while the central monitoring workspace auto-fills remaining space. Right-hand telemetry and incident inspector panels snap to a fixed `22.5rem` (`360px`). Gutter rhythm stays consistent at `1.5rem` (`24px`).
- **Tablet (768px - 1279px):** Collapses sidebar to an icon-rail (`4.5rem` / `72px`). Right inspector transforms into an off-canvas slide-over drawer. Content layout transitions to an 8-column layout with `1rem` (`16px`) gutters.
- **Mobile (< 768px):** Single-column stack with top operational metrics bar, contextual filter sheets, and bottom modal sheet for incident detail cards. Gutters lock to `1rem` (`16px`).

Vertical rhythm enforces an 8pt base grid for structural containers, with a 4pt sub-grid reserved for tight telemetry components, sensor badges, and micro-metrics.

## Elevation & Depth

Visual hierarchy uses crisp boundary separation combined with light, tinted ambient shadows to create optical clarity against light interfaces without visual weight:

- **Level 0 (Base Canvas):** Background `#F8FAFC`. Zero elevation, pure plane.
- **Level 1 (Standard Card / Table Rows):** Background `#FFFFFF`, border `1px solid #E2E8F0`, shadow `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)`.
- **Level 2 (Hover State / AI Detection Cards):** Background `#FFFFFF`, border `1px solid #CBD5E1`, shadow `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`.
- **Level 3 (Flyouts, Menus & Telemetry Tooltips):** Background `#FFFFFF`, border `1px solid #E2E8F0`, shadow `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.03)`.
- **Level 4 (Modal Triage / Critical Alert Overlay):** Background `#FFFFFF`, border `1px solid #CBD5E1`, shadow `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

**AI Scanning Overlays:** For active drone and dashcam machine-vision feeds, bounding targets use zero elevation shadows but apply an outer highlight border with `0 0 0 1px rgba(37, 99, 235, 0.2)` and backdrop micro-filters (`backdrop-blur: 2px`).

## Shapes

The design system implements balanced geometric contours:
- **Base Components:** Inputs, standard buttons, and small dropdowns use `rounded-md` (`0.375rem` / `6px`) or `rounded-lg` (`0.5rem` / `8px`) for a crisp, structural feel.
- **Cards & Data Modules:** Dashboards and AI bounding panels use `rounded-xl` (`0.75rem` / `12px`) and `rounded-2xl` (`1rem` / `16px`) to soften visual compartmentalization.
- **Indicators & Telemetry Badges:** Category pills, live status indicators, confidence meters, and filter tags use complete pill rounding (`9999px`) to maintain contrast with the angular layout grid.

- **Secondary / Outline:** Background `#FFFFFF`, text `#1E293B`, border `1px solid #E2E8F0`, radius `0.5rem`. Hover: `#F8FAFC`, border `#CBD5E1`.
- **Destructive (Emergency Halt / Reject Incident):** Background `#FEE2E2`, text `#DC2626`, border `1px solid #FECACA`. Hover: Background `#EF4444`, text `#FFFFFF`.

### Telemetry Badges & Chips
- Status badges use pill shaping (`rounded-full`), `px-2.5`, `py-0.5`, with `label-sm` typography.
- Structure contains a `6px` radial status dot pulse on the left edge:
  - *In Progress:* Dot `#3B82F6` with subtle ping animation, background `#DBEAFE`, text `#1D4ED8`.
  - *Resolved:* Dot `#10B981`, background `#D1FAE5`, text `#065F46`.
  - *Critical Hazard (Obstacle):* Dot `#EF4444`, background `#FEE2E2`, text `#991B1B`.

### AI Detection Cards & Bounding Meters
- Card containers use `rounded-xl`, white background, `1px solid #E2E8F0`, and level 1 elevation.
- Media viewport features an image canvas framed with subtle vector bounding corners in `#2563EB` or categorical colors.
- **AI Confidence Gauge:** Horizontal progress bar with `h-1.5`, background `#E2E8F0`, fill token using the category color. Paired with a `mono-metric` label displaying numeric confidence (e.g., `98.4% CONF`).

### Tabular Data Grids
- **Header:** Background `#F8FAFC`, uppercase `mono-code` labels, tracking wide, height `40px`, bottom border `1px solid #E2E8F0`.
- **Row:** Height `52px`, background `#FFFFFF`, hover state `#F8FAFC`, bottom border `1px solid #F1F5F9`.
- **Data Cells:** Uses `body-md` for description text and `mono-metric` for timestamps, GPS coordinates, and asset counts.

### Form Inputs & Selectors
- Background `#FFFFFF`, border `1px solid #CBD5E1`, text `#0F172A`, radius `0.5rem`, height `40px`, padding horizontal `0.75rem`.
- Focus state switches border to `#2563EB` with box-shadow `0 0 0 3px rgba(37, 99, 235, 0.15)`.

### Checkboxes & Radio Controls
- Checkboxes feature `rounded` (`4px`), border `1.5px solid #94A3B8`. Selected state fills `#2563EB` with white checkmark icon.
- Radio buttons feature standard circular tokens with dynamic center-point scale transitions.
